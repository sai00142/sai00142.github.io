# Saira Salman — Academic Website

A buildless academic homepage designed for GitHub Pages.

## Publish

1. Create a public GitHub repository named `sai00142.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/(root)`.
4. The site will appear at `https://sai00142.github.io/`.

## Files

- `index.html` — content and page structure
- `styles.css` — visual design and responsive layout
- `script.js` — menu and scroll-reveal behavior
- `antique-world-map.png` — full-width archival map artwork
- `cloud-large.png`, `cloud-medium.png`, and `cloud-wisps.png` — floating pixel-cloud layers
- `robots.txt` and `sitemap.xml` — search-engine discovery

## Before publishing

Review the public email address, project descriptions, and social links. The framed area above the Research Index intentionally reserves space for a future headshot. Future Research, Writing, Teaching, and CV pages can share the same stylesheet.
